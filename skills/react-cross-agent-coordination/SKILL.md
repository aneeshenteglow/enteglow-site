# React Cross-Agent Coordination Skill

## Pipeline Sequence

1. **Planner** -> Plan & component design.
2. **Implementer** -> TSX component & hook creation.
3. **Tester** -> `npx tsc --noEmit` + `npm run test`.
4. **Reviewer** -> Audit TSX, accessibility, and bundle performance.
